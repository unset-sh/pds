# pds

PDS packaging and customization for unset.sh.

This repository is being initialized for the organization delivery workflow.
It does not yet contain a runnable PDS package or deployment configuration.

Development changes target `staging`. Only a human may merge the same repository's `staging` branch into `main`.
Agents may review and merge eligible feature changes into `staging` after checks.

Product integration belongs in `backend`; environment provisioning and runtime
wiring belong in `deployment`.
